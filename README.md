# Recipe & Meal Planner

A full-stack web application built to manage recipes and organize weekly meal schedules.

## Tech Stack

* **Frontend:** React, Vite, Tailwind CSS, Axios
* **Backend:** Node.js, Express, Prisma ORM, PostgreSQL
* **Database:** PostgreSQL
